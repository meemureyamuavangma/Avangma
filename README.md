# Meemure Yamu Luxury Website

A responsive, monochrome, Apple-inspired static website for **Meemure Yamu with AVANGMA**.

## Included

- Official Meemure logo in the header and footer
- Home, Packages, Experiences, Campsites, Reviews, About, Tour Policy and Contact pages
- Black, ash and white visual system
- Responsive mobile navigation and bottom quick-action bar
- Package filters
- WhatsApp booking links and pre-filled booking form
- Local optimized WebP images
- No external JavaScript libraries

## Run locally

Open `index.html` directly in a browser, or run a local server:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Edit package information

Open `app.js` and update the `PACKAGES` array.

## Add verified reviews

Open `app.js` and replace the placeholder entries in the `REVIEWS` array with genuine customer feedback.

## Deploy

The folder can be uploaded to Netlify, Cloudflare Pages, GitHub Pages, cPanel hosting or another static hosting provider.
